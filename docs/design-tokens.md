# Design Tokens

Source of truth: `src/styles/design-tokens.css`

## Colors

| Family | Usage |
|---|---|
| Green (`#1B5E20` → `#E8F5E9`) | Primary brand, CTAs, headings, section backgrounds |
| Blue (`#0D47A1` → `#E3F2FD`) | Secondary accent, trust signals, links |
| Gold (`#F57F17` → `#FFFDE7`) | Highlights, ratings, special offers |
| Warm neutrals (`#F5F0E8`, `#FAF8F4`) | Section backgrounds |
| Glass (`rgba(255,255,255,0.08)` → `0.25`) | Overlay effects, nav blur |

## Typography
- **Font:** Inter (sans-serif), single family for headings + body
- **Scale:** 0.75rem → 3.75rem (xs → 6xl)
- **Weights:** 400, 500, 600, 700

## Spacing
8-point grid: 0.25, 0.5, 0.75, 1, 1.25, 1.5, 2, 2.5, 3, 4, 5, 6 (rem)

## Shadows
4 tiers (xs → 2xl) + colored shadow variants (green, gold, glass)
